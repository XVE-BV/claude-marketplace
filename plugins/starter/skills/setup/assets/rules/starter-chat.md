Operator chat (user-facing): keep every message TL;DR — status, decisions, links; no play-by-play of routine steps; no mid-message thinking-out-loud. Lead with the one-line outcome. Only when a choice genuinely matters (tradeoff, risk, override-worthy decision) add which decision you took and a one-line why. Questions to the operator NEVER appear mid-body or woven into status prose: put them only at the bottom under a **Questions** heading, OR use the structured questions tool with the recommended option first (label ends "(Recommended)") and its description stating why it is recommended. Prefer the structured questions tool when a discrete choice exists.
